# AION 2 Progression Companion — RU / EN

Помощник для развития персонажа AION 2 на русском и английском языках.

[Открыть сайт](https://evalionce.github.io/aion2-progress/) · [English](https://evalionce.github.io/aion2-progress/en/)

## Возможности

- Маршрут развития от первых заданий до эндгейма.
- Ежедневные и еженедельные задачи, события.
- Атлас 207 питомцев с картами, фильтрами и поиском на двух языках.
- Отслеживание рангов и прогресса коллекции.
- Переключение RU / EN с общими сохранениями.
- Автосохранение в браузере, импорт и экспорт JSON.

Прогресс хранится на текущем устройстве в браузере. Для переноса используйте экспорт и импорт.

## Локальный запуск

Нужен Node.js 20 или новее. Установка зависимостей не требуется.

```sh
npm start
```

Адрес: [http://127.0.0.1:4173/](http://127.0.0.1:4173/).

## Размещение

Сайт публикуется через GitHub Pages при обновлении ветки `main`. На хостинг загружается папка `public/`.
